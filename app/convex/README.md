# Convex backend

This directory is reserved for Menetap Convex functions, schema, indexes, scheduled jobs, and backend tests.

Planned initial domains:

- Users and roles
- Properties and partner onboarding
- Rooms, rates, and availability
- Bookings and booking status history
- Manual bank transfers and commissions
- Stay extensions and service providers
- Support tickets and audit logs

Initialize the Convex project with `npx convex dev` after the Convex project and GitHub repository are ready.
